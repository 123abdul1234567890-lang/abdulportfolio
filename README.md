# Abdul Rehman — Marketing Portfolio

Responsive, static HTML/CSS/JavaScript portfolio inspired by the **editorial, playful, orange-accented presentation style** of the Behance reference shared by the user. This is a custom implementation, not a copy of the referenced portfolio.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root (including `assets`).
3. Go to https://vercel.com/new and import the repository.
4. Choose **Other** as framework, leave the build command empty, and deploy.

## Update details
- Replace `assets/abdul-rehman.jpg` with an original high-quality portrait if available.
- Change email, phone, WhatsApp, and LinkedIn links in `index.html` if needed.
- The illustrated dashboard is deliberately marked as a concept and is **not** a real Meta Ads screenshot.
- Revenue, ROAS, ad spend, brand count and 20% sales increase are from the supplied Abdul Portfolio PDF; no additional client results were invented.
- Fonts use Google Fonts and require an internet connection for best appearance; fallback fonts are provided.
