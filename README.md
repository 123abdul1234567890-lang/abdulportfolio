# Abdul Rehman | Professional Portfolio Website

A mobile-friendly, single-page portfolio designed for sharing with recruiters, hiring managers and prospective clients. Static HTML/CSS/JS: no dependencies or build process.

## Files
- `index.html`: editable page content, links, SEO metadata
- `styles.css`: layout, colors, fonts and mobile styles
- `script.js`: mobile navigation and footer year
- `assets/abdul-rehman.jpg`: image extracted from the supplied portfolio (replace with a high-resolution, original portrait when available)

## Deploy to GitHub + Vercel
1. Create a new GitHub repository.
2. Upload all files, preserving `assets/` folder.
3. Import the repository at https://vercel.com/new
4. Select `Other` as framework, no build command. Root directory `./`.
5. Deploy.

- The case study in the supplied PDF does not name the client, timeframe, attribution window or data source. The site makes those limits explicit.
